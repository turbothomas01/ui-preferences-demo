# Thomas UI Preference Lab

A disposable, accessible HTML mockup for tuning Thomas's default UI preferences.

## Current baseline

- Dark mode first.
- Primary orange: `rgb(255, 122, 26)`.
- Blue accent for focus, links, and secondary actions.
- High contrast, large readable text, visible focus states.
- Left navigation for dashboards; top navigation available as a tweak.
- No color-only status; use text labels too.

Open locally:

```bash
xdg-open /home/thomas/Projects/ui-preferences-demo/index.html
```
